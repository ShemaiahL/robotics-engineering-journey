# Experiment 2: External LED Blink
## Project oveview
This experiment builds on my first Arduino LED Blink project. I assembled an external LED circuit using a 
breadboard and programmed an ELEGOO UNO R3 to blink a red LED.

## Objectives
+ Learn how to build a basic circuit using a breadboard.
+ Understand how to control external components using Arduino digital output pins.
+ Practice using resistors to limit electrical current.
+ Learn how to control LED blinking speed through programming.

## Hardware and Software
ELEGOO UNO R3
Breadboard
Red LED
330Ω resistor
Jumper wires
USB cable
Arduino IDE 2.3.10

## Circuit Description
I connected an external red LED to my Arduino using a breadboard, jumper wires, and a 330Ω resistor to limit current. 
I programmed digital pin 4 to control the LED.

## Testing and Results
Status: Successful
The external red LED successfully blinked on and off every 500
milliseconds, completing one full blinking cycle every second.

## What I Learned
* How to assemble an external LED circuit on a breadboard.
* How a resistor helps protect an LED.
* How to control external components using Arduino digital outputs.
* How to modify blinking intervals through code.

## Future Improvements
* Experiment with different blinking speeds.
* Add multiple LEDs.
* Use a push button to control the LED.
